# celldeathproject
This aims to study apoptosis between isotype control and anti-PD1 treated samples using an immunofluorescent-first approach. Microenvironments center around IF spots. We then derive and interpret transcription behavior that occurs in the vicinity. IF data comes from Imaris and spatial transcriptomic data comes from 10x Genomics VisiumHD.

- Hu Lab, Immunology, MD Anderson
