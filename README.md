# celldeathproject
This aims to study local apoptotic behavior between isotype control and anti-PD1 treated samples using immunofluorescent-labeled cell phenotypes from Imaris as well as spatial transcriptomic data from 10x Visium. File 1.1 is included as preliminary diagnostics, however, model predictors come from 1.2 and 1.3.

- Hu Lab, Immunology, MD Anderson
