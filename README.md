# celldeathproject
This aims to study local apoptotic behavior between isotype control and anti-PD1 treated samples using an immunofluorescent-first approach. Microenvironments center around IF spots and derive transcription behavior that occurs in the vicinity. IF data comes from Imaris and spatial transcriptomic data comes from 10x VisiumHD. File 1.1 is included as preliminary diagnostics, however, model predictors come from 1.2 and 1.3.

- Hu Lab, Immunology, MD Anderson
