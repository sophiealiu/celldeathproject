# celldeathproject
This aims to study apoptotic characteristics between isotype control and anti-pd1 treated conditions in MC38s using an immunofluorescent-first approach. Microenvironments center around phenotype-defined cells. We then derive and interpret aggregated signal in the vicinity. There are only four non-internally generated files, the raw data loaded from 10x Genomics VisiumHD and the Imaris manually selected spot coordinates.
