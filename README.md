# celldeathproject
This aims to study apoptotic characteristics between isotype control and anti-PD1 treated samples using an immunofluorescent-first approach. Microenvironments center around phenotype-defined cells. We then derive and interpret aggregated signal in the vicinity. IF data comes from Imaris and spatial transcriptomic data comes from 10x Genomics VisiumHD.

There are only 4 non-internally generated datasets: iso_raw.rds, pd1_raw.rds, apd1_coords.csv, and iso_coords.csv. These are the treated and control sample coordinates and Seurat objects loaded from 10x Genomics Visium HD data.
