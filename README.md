# celldeathproject
This aims to study apoptotic characteristics between isotype control and anti-pd1 treated conditions in MC38s using an immunofluorescent-first approach. Microenvironments center around phenotype-defined cells. We then derive and interpret aggregated signal in the vicinity. IF data comes from Imaris and spatial transcriptomic data comes from 10x Genomics VisiumHD.


- Hu Lab, Immunology, MD Anderson
