# celldeathproject
This aims to study apoptosis between isotype control and anti-PD1 treated samples using an immunofluorescent-first approach. Microenvironments center around IF spots. We then derive and interpret transcriptional behavior that occurs in the vicinity. IF data comes from Imaris and spatial transcriptomic data comes from 10x Genomics VisiumHD.

Begin with files in order. File 1.1 is there for initial exploration. There are only 4 non-internally generated files, iso_raw.rds, pd1_raw.rds, apd1_coords.csv, and iso_coords.csv. These are the treated and control sample coordinates and Visium HD data.
